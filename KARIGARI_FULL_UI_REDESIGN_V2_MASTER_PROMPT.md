## 7. AFTER BUILDING — SELF-CHECK (required, in this order)
1. **Build**: `npm run build` passes, zero TS errors, no console errors at runtime.
2. **Visual QA pass** (the user explicitly wants this): scan every restyled page for — overflow/oversize/undersize elements, misaligned or overlapping items, broken grids, text truncation/overlap, **image loading errors** (broken `src`, wrong `next/image` config for data URLs — use `<img>`/`unoptimized` for base64, `next/image` for `/public`), layout shift, and contrast/legibility. Fix each. Verify at **360px, 768px, 1280px**.
3. **Feature functionality pass**: click through every feature and confirm it still opens and works after the restyle — login, capture modal + all steps, marketplace → product → Buy, verify/passport, schemes apply, news/materials/insights load, AI assistant chat, notifications, marketing opt-in, language switch, admin pages. Nothing regressed.
4. **Animations** — minimal, tasteful, do NOT overdo: CSS-only (transitions + keyframes in `globals.css`); optional `@formkit/auto-animate` (~3KB) for lists/tab-swaps; **no framer-motion**. Add: gentle section fade-up on mount (small stagger), hover lift on cards, active-nav pill slide, filter-tab transitions, skeleton shimmer on load, subtle button/press feedback. 150–300ms ease-out. Honor `prefers-reduced-motion`.
5. **Performance — butter-smooth**: keep the shell in the layout so it doesn't remount per navigation; `loading.tsx` skeletons (new theme) for every route so tab-switches feel instant; `next/dynamic` for heavy/below-the-fold pieces (modals, map, charts, the AI chat panel); narrow API selects (no base64 in lists); compress/optimize images; `content-visibility:auto` on long lists; correct effect deps (no re-render/refetch loops); memoized `useLanguage`. No scroll jank, no layout shift.
6. **Final verification**: re-open each page and confirm it matches its reference image (or, for no-image pages, matches the shared language), data is real and in ₹ (₹ renders correctly — currency in a font that has the glyph), i18n works, and it's responsive.
